# config show


Show the details for a profile.

```shell
$ cx config show <name>
```

#### Options

| Argument | Required? | Default | Description |
|  ---  |  ---  |  ---  |  ---  |
| `<name>` | yes | — | Name of the configuration profile to show |

#### Examples

```shell
$ cx config show production
    Profile: production
    Organization: my-organization
    API Key: **********************
```
